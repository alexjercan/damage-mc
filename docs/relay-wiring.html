Hardware reference

Arduino + P1 button contacts

This diagram shows P1 on the first two-relay module. For P2, use a second module with the same contact wiring: D8 to IN1 (P2 +), D9 to IN2 (P2 -). See the full four-relay wiring reference before connecting power. The device has its own power source.

Button legs

On each four-leg button, the two wires go to opposite electrical sides. Confirm the sides with a continuity meter while the device is unpowered.

Off and on

All four inputs are HIGH at idle. A 75 ms LOW pulse on the selected pin energizes one relay. Use COM and NO, not NC.

Timing

There is a 25 ms gap between repeated presses. Firmware tracks separate P1 and P2 levels. The mod controls P1 and determines the hold time.

Startup

Opening the serial port can reset the Arduino. Pins are not controlled by firmware during reset. Test for clicks with the device disconnected. D13 is not used.

With the JD-VCC/VCC jumper fitted, each 5V module normally uses VCC and GND in parallel from the supply. Confirm both modules' ratings and the supply current capacity. This diagram shows P1 only and is not a pinout for every relay board.
